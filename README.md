# .github

This repository contains default community health files for my GitHub repositories.

## Contents

- **GitHub Actions Workflows**
  - `ci.yml`: A basic CI workflow for running tests

- **Issue Templates**
  - Bug report template
  - Feature request template
  - General issue template

- **Pull Request Template**
  - A standard pull request template with sections for description, type of change, testing, and checklist

- **Dependabot Configuration**
  - Automatic dependency updates for GitHub Actions and npm packages

## Purpose

These files serve as default community health files for all my repositories. For more information on how this works, see [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
