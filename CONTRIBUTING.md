# Contributing

Contributions are welcome. Start with the affected project's README and any local
contribution instructions: they determine setup, tooling, checks, and how changes
are accepted. These shared guidelines fill gaps across different kinds of projects.

## Issues and ideas

Search existing issues before opening a new one. For bugs, describe what happened,
what you expected, and how to reproduce it with a minimal example when possible.
Include the relevant version or commit and environment if they help diagnose the
problem. For feature requests, explain the underlying problem and desired outcome.
Questions and documentation problems are welcome through the general issue form.

Discuss substantial changes before investing a lot of effort. A clear proposal
helps establish whether the change fits the project's goals and maintenance needs.

## Pull requests

Keep PRs small and focused. Explain the resulting behavior, why the change is
useful, related issues, compatibility effects, and any remaining work. Review the
diff for unintended changes before submitting it.

Run checks appropriate to the project and change, and describe their results.
Add or update tests and documentation when the change needs them. Explain checks
that were unavailable or did not apply; documentation and configuration changes
may need review or a preview rather than application tests.

## Privacy and collaboration

Remove credentials, personal data, and sensitive logs from issues, examples, and
PRs. For suspected vulnerabilities, use the affected project's private reporting
route; see the [shared security routing guidance](https://github.com/Kian-Abdalkhani/.github/blob/main/SUPPORT.md#suspected-vulnerabilities).
Do not disclose vulnerability details in public issues or PRs.

Communicate respectfully, explain technical disagreements, and give other people
time to respond. Review, support, and merging depend on a personal maintainer's
available time; submitting a contribution does not guarantee it will be accepted.

See the [shared support guidance](https://github.com/Kian-Abdalkhani/.github/blob/main/SUPPORT.md)
for help requests. For changes to the shared defaults themselves, consult the
[maintenance guide](https://github.com/Kian-Abdalkhani/.github/blob/main/docs/maintaining-this-repository.md).
